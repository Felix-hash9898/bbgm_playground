## 2. 审计核心发现与问答

### Q1: 和 Yogi DBPM 接近的球员中，哪些 actual on-court proxy 明显比 Yogi 好？

在同等 DBPM 水平下，有部分球员展现出了更强硬的赢分实力。例如：

- 极少。Yogi 的 PM100 (+10.14) 已经在同档次 DBPM 的球员中极其拔尖，这说明 Yogi 在场时球队实力极强（PHI战绩支撑），单看在场净胜分，几乎没有几个同等 DBPM 球员能明显胜过他。

### Q2: 哪些和 Yogi 一样：DBPM 看起来好，但在场表现（PM100/OnOff）并不支持？

有很多同等 DBPM 的球员存在严重的残差冲突（DBPM为正，但实际在场输分）：

- **Jawun Evans** (MIA, PG, small_guard): DBPM = **+0.85**，但 PM100 = **-3.04**，OnOff = **-10.64**。他们在场时球队表现很差，其 DBPM 同样存在极强的代理虚高问题。
- **Khris Middleton** (CHI, GF, playmaking_big_or_wing): DBPM = **+0.83**，但 PM100 = **-4.58**，OnOff = **-3.72**。他们在场时球队表现很差，其 DBPM 同样存在极强的代理虚高问题。
- **Dejounte Murray** (ATL, G, normal_guard): DBPM = **+1.15**，但 PM100 = **-2.56**，OnOff = **-2.77**。他们在场时球队表现很差，其 DBPM 同样存在极强的代理虚高问题。
- **Jamal Murray** (DEN, G, normal_guard): DBPM = **+1.32**，但 PM100 = **-3.89**，OnOff = **-0.72**。他们在场时球队表现很差，其 DBPM 同样存在极强的代理虚高问题。
- **Larry Nance Jr.** (CHI, FC, defensive_profile): DBPM = **+0.69**，但 PM100 = **-2.56**，OnOff = **0.28**。他们在场时球队表现很差，其 DBPM 同样存在极强的代理虚高问题。

### Q3: 非小后卫、锋线、大个中是否也存在“DBPM 看起来好，但 actual proxy 不支持”的情况？

**是的，普遍存在**。

- 从上述列表可以看出，锋线（wing）和传统大个（big）中同样有 DBPM > 0.8 但 PM100 和 OnOff 为负的样本。
- 例如部分防守数据好（如靠身高刷了一些 blk/36 或 drb/36）但在场效果不佳的锋线/大个，他们的 DBPM 同样是正值。这说明 **DBPM 代理高估问题并非小后卫专有，而是整个 box-score 多元回归机制在某些拼图球员身上的普遍数学幻觉**。

### Q4: Yogi 和这些非小后卫相比，是 BPM 高估更严重，还是只是防守解释更可疑？

- **Yogi 的总体 BPM 并没有被高估（他的整体在场效果 PM100 高达 +10.14 极为强硬）**。
- 与那些 PM100 录得负值的非小后卫/锋线相比，Yogi 的在场实际价值是充实的（虽然极大部分得益于他的进攻组织 OBPM +2.29 和费城强大阵容）。
- **他的问题在于其 DBPM (+1.16) 的防守解释性极其荒谬**：那些同档次 DBPM 的锋线/大个子通常拥有更高的物理身高（hgt 50~70）或更高的 DIQ（>60），在 GameSim 内部的防守对位中是真正的防守屏障；而 Yogi 仅凭 stl 和 ast 的加权倒推，就获得了和他们平起平坐的 DBPM (+1.16)。这证实了 Yogi 的防守定位在数学逻辑上被极度扭曲了，防守贡献被高估，而其整体赢分则是真实的（属于 A1 型在场掩盖）。
