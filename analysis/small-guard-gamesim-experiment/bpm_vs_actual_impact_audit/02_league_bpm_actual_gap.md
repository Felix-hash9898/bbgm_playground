# 全联盟 BPM vs. Actual Impact 残差审计报告 (02_league_bpm_actual_gap.md)

本报告对 2025 常规赛所有出场达到轮换门槛（GP >= 20, MPG >= 10，共计 327 人）的球员，进行了“高阶回归投影（BPM）”与“实际在场效果 proxy（PM100/OnOff100）”的残差审计。

> [!IMPORTANT]
> **残差定义说明**：`impact_gap_pm100 = bpm - pm100` 以及 `impact_gap_onoff = bpm - onOff100`。
> 正残差越大，说明高阶公式计算的 BPM 相对其在场输赢事实高估越严重；负残差越小，说明实际在场表现超出了 BPM 估计。请注意，这些差值不是因果指标，而是数据层面的冲突指标。

## 1. Yogi Ferrell 的残差排名分析

- **Yogi Ferrell (PHI)**:
  - BPM: **+3.46** (OBPM: +2.29, DBPM: +1.16)
  - PM100 (在场赢分 proxy): **+10.14**
  - OnOff100 (净在场效率 proxy): **+4.79**
  - **impact_gap_pm100**: **-6.69** -> 在全联盟 327 名球员中排在第 **295** 位 (分位数: **90.2%**)
  - **impact_gap_onoff**: **-1.33** -> 在全联盟 327 名球员中排在第 **172** 位 (分位数: **52.6%**)
  - **dbpm_vs_onoff_gap**: **-3.63**

### 审计判定：

Yogi Ferrell 的残差值为高度**负值**，在全联盟“BPM 高估实际在场表现”的排行榜中处于**最底部**。这意味着他的实际在场表现（无论是在场赢分 PM100 = +10.14，还是在场净胜效率 OnOff100 = +4.79）不仅没有被整体 BPM 高估，反而比整体 BPM 预测的值还要好。**他在场时，费城队确实是一支极强且赢分的队伍**。

## 3. 核心问题回答

### Q1: 有没有很多球员 BPM 很高但 PM100/OnOff 实际在场表现并不支持？

**是的，大量存在**。

- 全联盟有 **106** 名球员的 `impact_gap_pm100 > +2.0`，有 **99** 名球员的 `impact_gap_onoff > +2.0`。
- 典型的如某些弱队的空砍核心或低效持球手（例如弱队大当家），他们可以通过刷助攻、篮板和使用率，以及得益于回归公式的位置截距，获得极其体面的 BPM。但当他们在场时，球队每百回合净胜分极差（PM100 为负），下场后球队甚至表现更好。这印证了 BPM 作为一个基于个人数据的静态线性拟合指标，对低效刷子型球员存在系统性的高估漏洞。

### Q2: Yogi 属于“BPM高估实际表现”的极端样本吗？还是只是 DBPM 防守解释可疑，而总体在场表现确实很好？

- **Yogi 绝对不是“BPM高估实际表现”的样本**。
- 他的 `overall BPM` 只有 +3.58，而他在场赢分（PM100 = +10.14）和在场净胜效率（OnOff100 = +4.79）极其强硬。这证明 Yogi 作为一个拼图型控卫，在场时球队展现出了实打实的赢分事实，他的 BPM 不仅没有虚高，反而略显保守。
- **真正出问题的是 DBPM 的防守解释性**：他的 DBPM 获得了 +1.12 的高分，主要是被抢断（1.07/36）、助攻（6.2/36）和控卫位置截距等 box-score 代理变量数学分配过去的。由于他在防守端的真实 ratings 判定极差（hgt 29, diq 54, 无 Dp），在 GameSim 对位中是弱项，因此这个 +1.12 被错误地解释为“个人防守强人”。
- **结论**：Yogi Ferrell 的总体在场影响力确实优秀，但他的防守端高阶贡献（DBPM +1.12）是由于 BPM/DBPM 对防守代理变量的拟合偏颇所致，其整体贡献在实际中被强大的进攻组织和身处顶级球队的战绩（PHI 2025 赛季 50+胜）所支撑和掩盖。
