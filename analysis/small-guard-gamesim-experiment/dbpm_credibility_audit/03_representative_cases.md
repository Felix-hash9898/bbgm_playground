## 2. 代表样本深度诊断与分析

### Yogi Ferrell (pid: 200) - 可疑组

1. **为什么选他**: 本审计项目核心主角。物理身高矮（72 in），评级身高极低（ratings.hgt = 29），防守智商中下（diq = 54），无任何防守徽章。但在 2025 常规赛交出了华丽的 **DBPM +1.16**。
2. **DBPM 为什么看起来好**: 他效力于费城（PHI，强队），其在场正负值受到了团队极高的 $\text{teamAdjBPM}$（+1.16）加成，且拥有良好的进攻输出（OBPM 2.29），在 box-score 回归中产生了防守优秀的假象。
3. **ratings 是否承认其防守**: 不承认。其防守 Composite 评级很低，在 GameSim 内线防守/篮板中都是严重劣势项。
4. **反事实适应性**: 极佳。用于检验扣减防守智商对他的实际球队防守效率（GameSim 丢分）有多大伤害。

### Ja Morant (pid: 1519) - 可疑组

1. **为什么选他**: 明星控卫代表。拥有极高的常规赛出场时间（35.3 MPG），防守智商极低（diq = 43，属于全盟后卫下游），无防守徽章，但在常规赛中斩获了 **DBPM +1.62** 的耀眼成绩。
2. **DBPM 为什么看起来好**: 莫兰特在场时进攻统治力极强（OBPM 5.81），同时其出色的弹跳与敏捷使他能收割较多抢断与篮板，从而被 BPM 回归公式判定为防守正资产。
3. **ratings 是否承认其防守**: 不承认。diq = 43 几乎是首发守卫防守底线。
4. **反事实适应性**: 极佳。测试当他从 diq 43 降到 28 时，其在场 35.3 分钟对 SAC/PHI 造成的实际失分变化。

### Saben Lee (pid: 1422) - 可信组

1. **为什么选他**: 小后卫防守天花板。虽然 ratings.hgt = 30，但 diq = 71 极高，且身背 `Dp` 徽章，常规赛 DBPM 录得 **+2.44**。
2. **DBPM 为什么看起来好**: ratings 强力支持，高抢断率加上在场防守端实打实的 Composite 贡献。
3. **ratings 是否承认其防守**: 承认。代表小体型防守的天花板极限。
4. **反事实适应性**: 极佳。对比 baseline 打折前后的战绩下滑程度。

### Trae Young (pid: 1840) - 可信组

1. **为什么选他**: 特殊样本。虽然 diq 仅为 56（低于60），但由于高速度和防守配置，重算中依然获得了 `Dp` 徽章，DBPM 高达 **+2.38**。
2. **DBPM 为什么看起来好**: 拥有外线防守技能徽章支撑，同时进攻统治力极强。
3. **ratings 是否承认其防守**: 部分承认（通过 Dp 技能）。
4. **反事实适应性**: 极佳。可以检验防守打折导致丢失 Dp 后，其防守表现的剧烈滑坡。

### Stephen Curry (pid: 146) - 预期负值组

1. **为什么选他**: 核心负值对照。高上场时间（30.7 MPG）， ratings.hgt = 37（略大），diq = 53，无 Dp 徽章，常规赛 DBPM 为 **-0.15**，基本符合预期。
2. **DBPM 为什么看起来差**: 虽然进攻很强，但金州勇士（GSW）2025 年的团队净胜分可能不支持高 teamAdjBPM，且防守数据没有超常表现，回归结果真实反映了其防守弱势。
3. **ratings 是否承认其防守**: 判定为弱势。
4. **反事实适应性**: 适合。用来校验本来就不防守的后卫，在进一步扣减 diq 后是否还会对球队产生破坏。
