# GROWTH NEXT 年龄构成拆分预注册

本轮比较预注册于云端运行前。原 K、N、L/M、O/Q、R、T 和 N＋R 裁定保留。N 的年龄构成与防守角色收益已有独立证据，八对现代档案也显示双向供给退化。将 N 的年龄段拆开，检验老将收益和双向副作用来自哪一部分。历史拟合评分的相关结构在现代留出不稳定。连续画像加入滞后的预测对 29–33 岁 NBA 盒分平均只改善 1.4%，对历史拟合评分反而退化，因此本轮不给球员添加类型开关或动量。

| 实验臂 | 共同基线 | 有区分的唯一机制 |
|---|---|---|
| K | 冻结 K | 无 |
| V | 冻结 K | N 的 29–38 岁构成项 |
| Y | 冻结 K | N 的 20–25 岁构成项 |

三臂都用 K 的生成与真实开档规则、伤病、分钟、市场、GameSim、年际随机项和评分边界。两臂只改变指定年龄段的同一年度评分增量。逐属性单步预检覆盖 18–42 岁、不同教练和边界，并核对共同随机调用的下一数值。

## 云端配对与定义

2021/77、78 与 2024/91、92，各十八季的 K/V/Y。2008/98 一个十八季 K/V/Y 配对，作为时期外保护。种子均未用于本项目此前的比较。现代为主要评价，不用 2008 微调。1998/2001 的原较早年代裁定保持原样。比较队列与轮换均来自正常游戏入口，沿用 `157`、`159` 的同口径 NBA 产出、技能组成、防守角色、双向和变化独立性指标。

- **V 主目标。** 两现代窗合并，28+ 产出构成平均绝对误差 ≤ .80 K，三年护筐与抢断角色留存平均绝对误差 ≤ .85 K。年轻构成误差 ≤ K+.02。以 §20 同口径的 30–40 岁相邻两季轮换报告崩跌。稳定角色要求同球队、两季均至少 500 分钟、分钟／使用率／首发率落在 §20 已冻结的变化范围。合并全轮换崩跌 ≤ K+.005，稳定角色崩跌 ≤ K+.0075。只在比率降低并在两个开档方向都一致时，称稳定角色崩跌得到改善。
- **Y 主目标。** 两现代窗合并，年轻产出构成平均绝对误差 ≤ .90 K，28+ 构成误差以及防守角色误差均 ≤ K+.02。Y 是年轻贡献的独立判别。它也满足全部保护后才会作为候选讨论。两臂都说明力量和单项尾部轨迹，试验不以总体年轻成长变低作为成功。
- **共同现代保护。** 原 P1 的接班、效率漂移、市场和生涯绝对门槛继续用于识别实质退化，原相对生涯条款由两窗等权 ≤1.05 K、各单独开档 ≤K+.03 取代。原轨迹护栏的年度变化独立性、星级更换和职业离队率保留。双向只保实质边界，后期两窗合并常规人次 ≥K−1，每窗 ≥K−1.75，合并攻防水平相关 ≥K−.06。开档与首次季前 POT 哈希必须与 K 相同，前两季首轮和年轻分钟、健康空窗、胜率与效率执行原 §22 玩法护栏。
- **2008 保护。** 报告历史年龄接班、生涯、效率、市场的 P2 结果和同种子 K 比较，生涯距离 ≤K+.03。OVR 与 55+/60+ 供给作描述性审计。现代和历史的 OVR70+ 人数均不作为采用目标，巅峰长度也只报告。
- **取舍。** V 若达到针对性目标和共同保护，保留进入后续必要组合验证。若 V 只改善角色构成，明确区分未解决的稳定角色崩跌。根据 V 与 Y 的实测双向表现解释 N 副作用，独立臂通过也不自动重新采用 N。云端结果公布后保留门槛和旧裁定。
