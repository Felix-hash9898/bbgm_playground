# R16.4 生成球员双向能力消融

真实档案与 K 开档对照表明双向缺口既出现在后期真实球员，也出现在生成球员。首年已选生成球员在年龄与身高组内的组织评分与防守评分关系弱于 NBA，速度贡献尤其不同；筛入常规轮换时关系进一步减弱。本实验只判别生成画像能否带来可用的独立改善。保护组继续冻结 K。

R = K + 在纯生成选秀届一次性重新配对组织技能与防守技能。原生成倍率、各项边际分布、参选年龄、真实评分和年度成长保持 K。按选秀年龄与身高组三段配对。组织量为 10×OIQ + 7×PSS + 3×DRB，防守量为 2×DIQ + SPD。优先交换能增加两者协方差的两名球员的 DIQ/SPD 组合。每人至多一组，任一项差 ≤12，原始 OVR 加权差 ≤2.25，每组交换对数不超过人数的四分之一。原始能力对与单项边际分布在组内守恒。交换后经 K 的同一入口重新计算 OVR 和 POT。单个球员能力变化只发生一次。

## 云端门槛

2024 开档，种子 86–89，每个种子 K/R 各 18 季。八单元必须通过引擎、开档等价和生成届日志核对，独立分支冻结。

- 双向球员主目标沿用 §18。模拟第 9–18 季，进攻前 30 且防守前 60、至少 1,000 分钟的球员，每季比 K 多 ≥1.0；攻防产出水平相关 ≥ K + .05。并要求生成常规球员的攻防水平相关增加 ≥ .05，报告每种子的结果与真实球员对应值。
- 现代保护使用该窗原 P1 门槛的相同阈值及归档 A/F/H。生涯距离两条相对门槛换成同窗同种子 K + .03 的绝对非劣效上限；其余 20 门槛保留。
- 年度成长与职业保护沿用 §19 的保护组。平均技能年变化绝对相关 ≤ .10，攻防年变化相关绝对值 ≤ |K|+.06；老将崩跌率 ≤ K+.005，26–29 岁球星留存、晋升及中老年离队同冻结门槛。通过时进入最终组合复核。目标达不到或有实质保护退化则暂缓使用。
